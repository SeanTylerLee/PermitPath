How it works

How PermitPath works

Build a permit route in any state, import a Texas TxPROS route when you have one, or unlock a company device with a fleet code. Watch each walkthrough below.

Any state

Build a route yourself

Drop start and end pins, then add waypoints from the paper permit. The free app includes 4 waypoints. Unlimited waypoints is $3.99 a month, or a company code from your fleet.

1

Set start and end

Pin the origin and destination from your permit so the trip matches the paper route.

2

Add waypoints

Drop the turns and corridor points from the permit. Paid plans have no waypoint cap.

3

Start navigation

Follow the line you built on iPhone, iPad, or Android. Share the same route with the office.

4

Stay on the line

Navigation does not reroute for traffic or accidents. Compare the screen to the permit as you drive.

Texas

Import a Texas TxPROS permit

After TxDMV issues your permit, upload the PDF or scan the QR. PermitPath imports the official TxPROS route. This is not AI guessing or parsing written directions. Texas import is a paid feature. More detail on Texas Permits.

Option 1

Upload the PDF

Use the original PDF of your Texas oversize permit. PermitPath reads the TxPROS permit from that file and imports the official route.

Option 2

Scan the QR code

Scan the QR code on the Texas permit with PermitPath. That pulls the same official TxPROS route into the app.

Fleets

Enter a company code

The office buys codes on Fleet Solutions. One code unlocks one company device. Drivers do not buy the app on that device.

1

Get a code from the office

Each open code is for one phone or tablet. Ask dispatch for the code assigned to your unit.

2

Open Company access

In PermitPath go to Settings → Subscription → Company access.

3

Enter the code

That device unlocks unlimited waypoints for the paid period. If a device is replaced, the office can request a replacement code.
